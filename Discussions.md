## 📝 Discussion Guidelines

### ✅ Do:
- **Be respectful and inclusive** - Welcome users of all skill levels
- **Provide context** - Include details about your environment and use case
- **Use descriptive titles** - Help others find relevant discussions
- **Search before posting** - Check if your question was already answered
- **Mark solutions** - Help future users find answers quickly

### ❌ Don't:
- **Post duplicate content** - Use existing discussions when possible
- **Share sensitive information** - Keep code and data examples generic
- **Spam or self-promote** - Keep discussions relevant to the project
- **Be negative or critical** - Provide constructive feedback instead
